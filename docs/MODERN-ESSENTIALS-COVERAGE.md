# Modern Essentials presentation coverage

24 presentation images: one collection cover, 20 screen explorations, and three reference sheets.

## Screen coverage

- Entry and session: main menu, pause, save/load with empty slot, loading, difficulty, home hub.
- Settings: audio, video/display including UI scale and safe area, accessibility, controls/rebinding with conflict feedback.
- Play and progression: inventory, equipment comparison, journal, gameplay HUD, rewards, world map, radial selection.
- Commerce and recovery: illustrative currency store, quit/overwrite/delete/save failure dialogs, checkpoint retry.
- Reference sheets: components and interaction states, navigation/item icons, keyboard/mouse/controller prompts.

## Presentation behavior

All thumbnails flow down the document without an internal scrollbar. Selecting one changes the main preview. Full-size dialog supports previous/next, arrow keys, Escape, and return focus. Full-size WebP files and small lazy-loaded thumbnails accompany preserved PNG originals.

## Production handoff still required

These images establish visual direction. They are not editable components or a functioning game interface. Before sale, build consistent source components, clean and export individual icons and transparent assets, reconcile all typography and interaction states, test navigation and accessibility in the target engine, and finalize licensing, file formats, dependencies, and pricing. Public availability remains in planning.
