# Havenworks — collection coverage

Sixth storefront collection: strategy, simulation, and management interfaces with chunky low-poly 3D artwork. 24 presentation boards: a cover, 20 screen/flow studies, and three reference sheets.

## Visual direction

Faceted settlement buildings, workers, resource miniatures, and terrain. Thick teal frames, warm ivory panels, dark evergreen text, amber primary actions, and coral warnings. Management views pair the settlement context with resource counts, costs, capacity limits, staffing, and actionable alerts.

## Production handoff

These are raster presentation concepts. Editable components, transparent exports, game logic, and engine integration remain to be built. Before release, standardize the example economy, capacity values, worker totals, time units, chart scales, and progress fills across boards. Finalize input mappings, controller focus, scalable panels, localization, and safe-area rules. Validate dense dashboards and placement tools at the intended game resolution, plus touch ergonomics and non-color overlay cues in-engine.
