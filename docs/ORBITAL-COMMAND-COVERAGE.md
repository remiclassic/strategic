# Orbital Command presentation coverage

29 presentation images: one collection cover, 25 screen explorations, and three reference sheets.

## Coverage

- Session: main menu, pause, save/load including empty slot, loading/travel, difficulty, command home hub.
- Mission: board, briefing, tactical flight HUD, results/rewards, failure/retry.
- Ship and crew: systems/power, loadout/comparison, cargo/inventory, crew assignments, research/upgrades.
- Navigation and communication: star map/routes, transmission log/responses, radial commands.
- Supporting flows: station exchange, audio, video/display, accessibility, rebinding/conflict, confirmations/recovery.
- Reference: component interaction states, navigation/module icons, keyboard/mouse/controller prompts.

## Presentation and files

All thumbnails extend down the document without an internal scrollbar. The featured preview and full-size dialog support previous/next navigation. The dialog supports arrow keys, Escape, and return focus. Original PNGs are preserved in design/orbital-command; optimized WebP images and thumbnails are in public/images/game-ui/orbital-command. Prompts and original source paths are in orbital-mockup-prompts.json. Artwork was created with the built-in imagegen tool using the collection cover as a style reference.

## Production boundary

These are presentation concepts. Before sale, build editable components and individual assets, reconcile typography and icon details, establish consistent interaction states, test responsive layouts and input navigation in the target engine, and publish delivery formats, dependencies, license, and pricing. The website continues to show planning status and does not promise an available game-ready pack.
