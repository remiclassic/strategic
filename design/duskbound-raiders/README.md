# Duskbound Raiders presentation artwork

The numbered PNG originals correspond to src/data/dusk-gallery.ts. Prompts and source paths are recorded in docs/dusk-mockup-prompts.json; artwork was created with the built-in imagegen tool.

From website/, recreate optimized gallery images and thumbnails with:

    node scripts/import-dusk-mockups.mjs docs/dusk-mockup-prompts.json

See docs/DUSKBOUND-RAIDERS-COVERAGE.md for visual direction, coverage, and the production handoff.
