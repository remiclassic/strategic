Original PNGs are stored in this directory. Optimized WebP images and small thumbnails are in `../../public/images/game-ui/fantasy-adventurer/`. The exact prompt sets and generation source paths are in `../../docs/fantasy-mockup-prompts.json` (original 12) and `../../docs/fantasy-gap-prompts.json` (10 additions).

The website gallery supports thumbnails, previous/next controls, an enlarged modal, left/right arrow keys inside the modal, Escape to close, and return of keyboard focus to the opening control. The homepage uses the collection cover.

These are flattened AI-generated presentation images. They are not separated sprites, editable layered source, final typography, or implemented game screens. Item counts, character details, text, and component shapes may vary between images; a production pack needs a normalized component system and individually authored/exported assets. The main menu, map, settings, and save/load images explore extensions beyond the originally proposed six-screen scope.
